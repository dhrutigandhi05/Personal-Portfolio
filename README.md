# Dhruti Gandhi Portfolio
A personal portfolio website built with React, Vite, Bootstrap, and Framer Motion. This site highlights my education, work experience, projects, technical skills, resume, and contact links.

## Live Site
[View Portfolio](https://dhrutigandhi.netlify.app)

## Tech Stack
- React.js
- Vite
- Bootstrap
- Bootstrap Icons
- Framer Motion
- JavaScript
- CSS
- Netlify
- GitHub Actions

## Features
- Responsive navigation bar
- Animated hero section
- Education and experience sections with logos
- Interactive project reveal cards
- Skills grouped by category
- Interactive contact section
- Resume link
- Mobile responsive layout
- GitHub Actions deployment pipeline to Netlify
